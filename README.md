# MU PDL Survival - Protótipo

Build v2 corrigida.

## Controles
- W: andar para frente
- S: andar para trás
- A/D: girar personagem
- Clique esquerdo: atacar
- TAB: esconder/mostrar HUD

## Alterações desta versão
- Câmera fixa em terceira pessoa atrás do personagem, um pouco acima.
- Zoom removido.
- Grid do chão removido.
- Terreno com textura procedural de grama.
- Árvores, pedras, arbustos, praça, castelo e casas adicionadas.
- Montanhas nas bordas do mapa.
- NPCs reduzidos e espalhados.
- Respawn individual em 15 segundos após a morte.
